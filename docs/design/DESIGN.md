## 0. 원칙 (typewriter-refs §8.1 → 규칙)
1. **장식은 크롬, 종이는 비운다.** 종이(캔버스)엔 색·줄 가이드·마진 여백 외에 아무것도 없다(§8.1-1, BRIEF §4).
2. **베일 = 툴바 = 눈금자.** 툴바 하단 1px 눈금 위에 마진 스톱 마커 2개(§8.1-2). 마커는 평소 **정적 표시**, "속지 편집 모드"에서만 드래그(COUNCIL 좌석5 #2, PLAN §12-9).
3. **2색 리본 = 색 시스템.** 검정 잉크 기본 + 빨강 단일 포인트, **화면당 빨강 면적 1% 미만**(§4 B 권고). 리본 토글 의미는 하나: **현재 펜 색을 검정↔빨강으로** (다른 색이면 검정으로) — PLAN §12-9.
4. **크롬 다크와 종이 다크 분리**(Ulysses, §8.1-4). 잉크는 반전이 아니라 의미색 재매핑(§7.1) — 렌더러(`InkTheme`) 책임.
5. **재질 없음.** 코드로 그린 금속·유리·고무 금지(§8.2). 스큐어모피즘은 "서랍/카드/프레임" 구조만.
6. **글자 최소·아이콘 위주.** 모든 아이콘 버튼 = `contentDescription` + 툴팁 (BRIEF §4, PLAN §1.2 접근성). 모노 활자는 숫자·눈금·단축키에만(§8.2).
7. **마우스 전용(Windows)으로 전 기능**이 1차 기준, 터치는 보너스(PLAN §12-7, A9).

## 4. 모션
- 조작 반응만(눌림·시트 열림·페이지 피드 미세 그림자). 배경 모션 없음(BRIEF §2 "타자기 느낌").
- `reducedMotion` 토큰(설정) → 모든 장식 모션 0(`snap()`), 툴팁 즉시, 시트 전환 없음. **레이저 페이드는 기능이므로 유지**(COUNCIL 좌석5 #8).
- 페이지 피드 = 전환 시 페이지 상단 그림자 암시만, ≤150 ms(D-007).

## 6. 접근성 체크리스트 (PLAN §1.2)
- [x] 모든 아이콘에 비어 있지 않은 `contentDescription` — `PlatenIcons.all` 상수 + 테스트 `IconsAccessibilityTest`.
- [x] 툴팁 = `TooltipBox` 전수(`ToolIconButton` 래퍼만 사용).
- [x] 타깃 ≥48dp(Material 기본 `minimumInteractiveComponentSize`), Windows 40dp 는 `uiDensity` 로.
- [x] 텍스트 대비 AA: `ink`·`muted.text`·`red`(라이트) 전부 ≥4.5:1 (§1 표).
