## 1. 한 줄
굿노트·스타노트·삼성노트를 분해(REA)해 원리를 가져온 **타자기 느낌의 손글씨 노트앱**.
차별점: **외부 브러시 불러오기** (Procreate · Photoshop 브러시 파일 → 내 브러시로 변환).

## 2. 확정 사항 (재질문 금지)
| 항목 | 결정 |
|---|---|
| 기존 앱과의 관계 | 완전 클린 슬레이트. 이전 앱 iwhg(Kotlin+Compose+androidx.ink)와 코드 무관. 실측된 사실만 참고 지식으로 사용 |
| 플랫폼 | 1순위 Android — 갤럭시 탭 S9+(SM-X810), S펜, 사이드로드(스토어 배포 없음). 2순위 Windows 11 노트북 — **펜 입력 불가(마우스/터치만)**, 열람 + 가벼운 편집 전용(필기 없음). 편집 범위 상세 `[미정]` Q7 |
| "타자기 느낌" | 비주얼 룩 + 구조 은유. 모션·소리·활자 텍스트 입력은 정체성 요소 아님(조작 반응 모션은 기본 취향, reduced-motion 예외) |
| 미감 | 시안 2방향 비교 후 사용자가 선택. (A) 실사 스큐어모픽(이미지 에셋) / (B) 모던 미니멀 + 타자기 암시(모노 활자·크림 종이·검정/빨강 2색, 기계 그림 없음). 픽셀/도트·1px 선화 계파 제외 |
| 스택 | 리서치 + 스파이크 후 결정. 후보: Flutter(Impeller) / KMP + Compose Multiplatform / 네이티브 2개(Kotlin + WinUI·C#) / head 추가안. 판정 축: S펜 지연·필압·틸트·호버·팜 리젝션, Windows 포인터, 캔버스 성능, 패키징, 빌드 환경 |

| REA 범위 | ① 기능·UX 동선 ② 필기감·잉크 렌더 ③ 파일 포맷(.goodnotes · 스타노트 · .sdocx) ④ 템플릿·속지 생태계 |
| REA 자료 | 공개 자료만(스토어·공식 도움말·개발자 문서·리뷰·영상·공개 포맷 분석·오픈소스 파서). 로그인·유료 벽·DRM 우회 금지. 타사 코드·에셋 복사 금지 — 원리와 수치만. 실측은 로컬 숙제 |
| 진행 방식 | Q&A → 리서치 → 계획서 → 승인 → 구현. 작은 수정만 예외 |

## 2b. 인터뷰 확정 (2026-10-24, 재인터뷰 3라운드 완료 — D-011~D-013)
| 항목 | 결정 |
|---|---|
| 앱 이름 | **Platen** (`platen`). 패키지명·Windows 식별자 충돌은 리서치에서 확인 |
| 1차 플랫폼 | **Android(필기 전체) + Windows(편집)**. Windows는 펜 없음(마우스/터치): 올가미 선택·이동·삭제 / 페이지 관리 / 텍스트 박스 / 이미지 삽입. 마우스 필기 없음 |
| 브러시 임포트 | **Procreate(.brush/.brushset) + Photoshop(.abr) 둘 다 1차**. 리스크 1순위 — 해독 실패 시 한쪽 축소를 B안으로 |
| 브러시 성격 | 단계적: 1차 필기 위주(펜·만년필·연필·형광펜), 모델·임포터는 스탬프/텍스처까지 담도록 설계 |
| 동기화 | **Google 로그인 + Google Drive** 1차. 자체 서버 없음. 오프라인 우선. OAuth 클라이언트·Cloud 프로젝트 = 사용자 로컬 숙제. 테스트 사용자 모드 제약은 리서치 확인 |
| 필기감 기준점 | **지연** = 삼성노트 / **필압·매끈함(스무딩)·끝처리(테이퍼)** = 스타노트, 단 **사용자 조절 가능**(굿노트식) / **만년필** = 스타노트 / **연필** = Notes+(iOS) |
| 기본 입력 정책 | 손가락 = 팬/줌 + 손가락 필기 토글 / S펜 옆버튼 + 긋기 = 지우개 / 펜 호버 중 손가락 무시 |
| 제스처 설정 | 손가락 제스처 + S펜 옆버튼 동작을 매핑 테이블로 사용자 설정. 펜 더블탭·길게 누르기는 후속 |
| PDF·타사 포맷 | PDF 가져오기+주석 **1차** / PDF 내보내기 **1차** / .sdocx 읽기·쓰기 **후속** / .goodnotes 읽기 **리서치 후 판정** |
| 구조 은유 | 마진 스톱 = 줄 가이드·속지 여백 → UI 구조 / 캐리지 = 페이지·노트 이동 → UI 구조 / 페이지 피드 → 시각 암시만 / 탭 스톱 → 후속 / 플래튼 노브 → 안 함 |
| 손글씨 인식 | 1차 제외, 스트로크 보존. 검색은 제목·텍스트 박스 |
| 추가 기능(3R) | **표 삽입**(행·열·선 스타일·셀 크기 조절 `[가정]`) 1차 / **레이저 포인터**(일시 표시 후 사라지는 획, 색·지속 시간 조절 `[가정]`) 1차 / **설정 화면**: 필기 파라미터(필압 커브·스무딩·테이퍼)·제스처·UI 를 사용자가 조절 |
| 실행 모드 | **혼합**: M0(스택 스파이크)~디자인 잠금까지 manual, 이후 auto. 실기기 판정은 항상 멈춤 |
| REA 대상 | 굿노트 · 스타노트 · 삼성노트 · **Notes+(iOS, 연필 질감·펜 로스터 참고)** |

## 3. 완료 정의 (1차 출하 / MVP) — 확정
> 갤럭시 탭 S9+에서 Google 로그인 후, 지연은 삼성노트·필압/매끈함/끝처리는 스타노트 수준(사용자 조절 가능)으로 빈 속지나 PDF 위에 필기하고(펜·만년필·연필·형광펜·지우개·올가미·되돌리기), Procreate·Photoshop 브러시 파일을 가져와 내 브러시로 쓸 수 있으며, 그 노트가 Drive로 동기화되어 Windows 앱에서 동일하게 보이고 올가미 이동·삭제·페이지 관리·텍스트·이미지 편집이 되며, PDF로 내보낼 수 있다.

(3R 추가: 표 삽입 · 레이저 포인터 · 설정 화면 포함. 수치 합격선은 PLAN.md에서 정의.)

## 4. 제약
- 클라우드 환경: 실기기·로컬 파일·태블릿 APK 접근 불가 → 실측/APK 분해는 `docs/LOCAL_TODO.md`로 분리.
- 빌드 산출물(APK·Windows exe)은 가능하면 이 환경에서, 아니면 GitHub Actions Artifacts.
- 의존성·외부 설치·스펙 변경은 승인 필요(계획서 목록 → 승인, 이후 추가는 사유와 함께 질문).
- 타사 에셋·코드 복사 금지.
- UI: 글자 최소·아이콘 위주(툴팁·접근성 이름 필수, 보이는 아이콘 = 실제 명령). 조작 반응 애니메이션 기본, 배경은 조용히.
- 도구 앱: 캔버스 가독성·필기감 > 장식. 타자기 장식은 크롬(툴바·사이드·페이지 틀), 종이는 깨끗하게.
- 다크 모드: 검정 잉크 자동 반전 + 형광펜이 다크에서도 보일 것.
- 판정은 수치·증거로. 기준점 = 굿노트·스타노트·삼성노트.
- 완료 보고는 실제 산출물과 증거로만.
